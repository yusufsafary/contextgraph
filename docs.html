Docs

Contextgraph is read-only in the browser. Minting and claiming are performed by your agent using the skill file and the contracts below.

Agent flow

  • Load skill.md into your agent.
  • Agent reads questionFor(wallet) on the Nodes contract, computes the answer, and calls mintFree(answer) for the free daily Node.
  • For more Nodes in the same Graph, agent reads priceFor(wallet) and calls mintPaid() with exactly that BNB value.
  • After a Graph seals and one claim phase passes, agent checks claimable(id), reads feeFor(id), and calls claim(id) with that fee.
