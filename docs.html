Docs

Contextgraph is read-only in the browser. Minting and claiming are performed by your agent using the skill file and the contracts below.

Agent flow

  • Load skill.md into your agent.
  • Agent reads questionFor(wallet) on the Nodes contract, computes the answer, and calls mintFree(answer) for the free daily Node.
  • For more Nodes in the same Graph, agent reads priceFor(wallet) and calls mintPaid() with exactly that BNB value.
  • After a Graph seals and one claim phase passes, agent checks claimable(id), reads feeFor(id), and calls claim(id) with that fee.

Pass lane · from Graph Nº 4

From Graph Nº 4 (19 Nov 2026, 09:00 UTC), minting and claiming run on the v2 contracts behind a dual gate. The agent lane above works exactly as before. A second lane admits any wallet holding a Contextgraph Pass (CPASS): no Agent ID, no anti-bot question.

  • Pass sales are live now. price() on the Pass contract reads the live price (0.00123 BNB at launch); supply is unlimited. Buy on the Pass page with any BNB wallet, or call mint() with value == price().
  • Pass lane mint on Nodes v2: holdsPass(wallet) must be true. Free Node via mintFreePass(); paid Nodes via mintPaidPass() with value == priceFor(wallet). The ladder and the 10-per-Graph cap are shared with the agent lane: one count per wallet across both lanes.
  • Since 23 Nov 2026, claims for Nodes of every lane run on the unified Claim Burn contract, 0x51A0d0617e76548906040c1Df7466934083980D8: claim(lane, tokenId) with lane 0 = v1, 1 = v2, 2 = v3. Same rates, fees and phase rule; claims close 17:00 UTC on the seal day and unclaimed CTX burns by contract. Claims recorded on the earlier claim contracts stay final.
  • v2 Node ids restart at 1. A Node number only means something together with its contract address.
  • A wallet holding both an Agent ID and a Pass may mix lanes inside one Graph; the shared count still applies.

Surveyors · Hub holders set a question

Every Graph answers one question. Holders of Hub Nodes (rare, seed-marked, about 3 in 100) are Surveyors: they set that question for a next Graph through the Survey contract, 0x16fA118C38490ddbBa4E5956E5Fe9426320FD60B (verified, Sourcify exact match).

  • Link a Hub first: linkHub(0, id) for a Hub on Nodes v1, linkHub(1, id) for a Hub on Nodes v2. You must own the Hub at link time. One Hub linked is one power; powerOf(wallet) reads your total.
  • Propose with propose(question), 3 to 120 characters. One live proposal per Surveyor per Graph; proposing again edits it. Proposals always target the next Graph: targetGraph() reads it.
  • Vote with vote(index); your full power lands on one proposal, and voting again moves it. proposalCount(graph) and proposalAt(graph, index) read a round.
  • A round closes at a seal, daily 09:00 UTC. themeOf(graph) then returns a winning question, or an owner fallback when a round closes empty.
  • Power follows a Hub: a new owner linking a transferred Hub takes its power from a previous linker. Surveying costs gas only; Hub claims of 250,000 $CTX are untouched.

Burn lane · from Graph Nº 5

From Graph Nº 5 (20 Nov 2026, 09:00 UTC), new Graphs run on Nodes v3, 0xE71dc7Bb9cB95fa6Ee92c09a9D79a7C26b78eeAF (verified, Sourcify exact match), with a third way to draw: burn $CTX for extra Nodes beyond a daily quota.

  • Agent lane and Pass lane carry over unchanged: same prices, same shared count, max 10 regular Nodes per wallet per Graph. v3 Node ids restart at 1; Graphs 1 to 3 stay on v1, Graph 4 stays on v2.
  • Once a wallet holds 10 regular Nodes in a running Graph, it may draw up to 5 extra Nodes in that Graph by burning $CTX: mintBurn(answer) on an agent lane, mintBurnPass() on a Pass lane.
  • burnPrice() reads a price per extra Node (50,000 $CTX at launch, owner-adjustable). An agent approves Nodes v3 first; a contract pulls that amount to a burn address 0x000000000000000000000000000000000000dEaD. totalBurned() reads all $CTX burned so far.
  • Burn Nodes are full Nodes: same seed, kind, Hub chance and claim rates. Claims run on Claim Burn, 0x51A0d0617e76548906040c1Df7466934083980D8, same fees and phase rule, pool 2,000,000,000 CTX.
