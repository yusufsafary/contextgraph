How it works

From URL to insight
in four steps

01

Paste GitHub URL

Drop any public or private GitHub repository URL into the input field.

02

Repository scan

ContextGraph traverses the repository tree, resolving imports, exports, and dependencies.

03

Generate graph

An interactive architecture graph is rendered with nodes, edges, and cluster groupings.

04

Explore insights

Click any node for AI-generated explanations, dependency chains, and risk signals.
