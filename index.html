What it does

01 Architecture &
Dependency Graph

See the full picture before touching a single file

ContextGraph renders an interactive node graph of your repository — folders, modules, and their relationships. Identify core paths and peripheral code at a glance. Drag nodes, zoom in, and click any module for a detailed breakdown.

02 AI-Powered
Code Intelligence

Plain-language explanations for every module

Click any node and receive a concise, accurate description of what that folder or file does, what it depends on, and why it exists. Built for engineers joining an existing codebase — not for reading 10,000 lines of undocumented code.

03 Entry Points &
Risk Detection

Find where execution starts and where debt hides

Automatically detect application entry points, request flows, and high-complexity hotspots. Surface modules with excessive dependencies, circular imports, or stale code — before they become incidents. Designed for both onboarding and architecture reviews.
